# 新能源工具箱（NEW-ENERGY-TOOLBOX）

![Version](https://img.shields.io/badge/version-V1.0-blue) ![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20Browser-green) ![Language](https://img.shields.io/badge/language-HTML%20%2F%20JavaScript-orange) ![Author](https://img.shields.io/badge/author-hiterls1992-lightgrey)

> 面向新能源、测绘与电气工程场景的**纯前端离线工具合集**。
> 所有计算均在浏览器本地完成，不上传任何数据；零依赖、零安装，双击即用。

---

## ✨ 特性

- **零依赖**：每个工具均为单文件 HTML，无框架、无第三方库、无服务端；
- **离线可用**：计算、查询、脚本生成全部在浏览器本地完成，数据不外传；
- **双主题**：暗色科技风 / 浅色工程风一键切换，全工具观感统一（设计令牌见 [样式规范.md](样式规范.md)）；
- **面向 CAD**：坐标展点、八边形生成等工具直接输出命令行版 CAD 脚本（`-TEXT` / `-LAYER` 命令行命令，避免对话框）；
- **工程闭环**：输入 → 校验 → 计算 → 结果 → 规范限值判断 → 预警，关键结果附计算公式与依据。

## 🧰 工具清单（V1.0 · 共 9 个）

| # | 工具 | 功能说明 | 输出 |
|---|------|----------|------|
| 1 | **2000坐标与经纬度互转** | CGCS2000 平面坐标 ↔ 经纬度双向转换，自动识别带号与坐标方向（高斯-克吕格投影） | 单点结果 / 批量 CSV |
| 2 | **CAD展点** | 测量坐标自动颠倒换算生成 CAD 展点命令，支持 Excel/Word 表格直接粘贴 | `.scr` 展点脚本 |

| 4 | **XY与AB坐标转换** | 两组对照点解算平面相似变换参数（平移+旋转+比例，支持 k=1 刚体拟合），CGCS2000 与施工局部坐标 AB 互转 | 单点结果 / 批量表 / CSV |
| 5 | **导线输送容量计算** | 钢芯铝绞线允许载流量、输送容量、经济电流密度、电压降落与线损（依据 DL/T 5582-2020） | 计算表 / 经济电流密度对比 |
| 6 | **新能源项目环境效益计算表** | 年上网电量测算节约标准煤、碳粉尘、SO₂、NOₓ、CO₂ 减排量 | 计算表 / 成果描述话术 |
| 7 | **批量新建文件夹** | 批量粘贴名称 → 校验 Windows 非法字符/重复项（支持子目录）→ 生成批处理 | `.bat` 脚本 |
| 8 | **雪压风压查询** | GB 50009-2012 表 E.5 全国 667 地区雪压、风压（R=10/25/50/100）与基本气温查询 | 查询结果 / 可复制文本 |
| 9 | **热轧型钢截面特性查询** | 工字钢、槽钢、等边/不等边角钢（GB/T 706-2016）与 H型钢、HK型钢、剖分T型钢（GB/T 11263-2024）截面尺寸与特性（A/I/i/W/外表面积/重心）查询，共 1160 规格 | 查询结果 / 可复制文本 |

## 🚀 使用方法

1. **下载使用**：点击 `Code → Download ZIP` 解压，或 `git clone` 本仓库；
2. 双击 **`新能源工具箱V1.0.html`**（建议 Chrome / Edge 浏览器打开）；
3. 左侧导航选择工具，各工具也可单独双击打开（独立打开时右下角有主题切换按钮）。

> 无需安装任何运行环境；如需在离线电脑使用，拷贝整个文件夹即可。

## 📁 目录结构

```
NEW-ENERGY-TOOLBOX/
├── 新能源工具箱V1.0.html    # 主框架（侧边导航 + 内容区 + 首页卡片）
├── 样式规范.md               # UI/样式开发标准（设计令牌、骨架模板、验收清单）
├── tools/                    # 工具页（单文件 HTML，文件名 = 导航命名）
├── css/
│   ├── dark/                 # 暗色科技风主题（每工具一个 CSS）
│   └── light/                # 浅色工程风主题（同名同选择器结构）
└── data/                     # 规范数据（GB50009 表 E.5 及热轧型钢标准数据；CSV 经 data/gen_*.py 生成 .js 供查询工具引入）
```

## 🎨 主题与样式规范

两套主题通过 `localStorage["nbx-theme"]` 切换（`dark` 默认 / `light`），主框架与工具页联动换肤。所有界面元素（页头横幅、按钮、表格、输入框、圆角分级）遵循统一设计令牌，新增/修改界面前请阅读 [样式规范.md](样式规范.md)。
