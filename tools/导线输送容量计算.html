📐载流量计算公式推导 (DL/T 5582-2020 / 电力工程设计手册)

1. 热平衡方程 (DL/T 5582-2020) — 公式 (3-71)

  I² · R't = WR + WF − WS
      ⇒  I = √[(WR + WF − WS) / R't]

2. 允许温度下的交流电阻

  R't = R20 · [1 + 0.004·(Tc − 20)] · β
      α = 0.004  1/℃   —— 铝电阻温度系数
      β = 1.004          —— 集肤效应系数

3. 辐射散热功率 WR — 公式 (3-72)

  WR = π · D · E1 · σ · [(Tc+273)⁴ − (Ta+273)⁴]
      σ = 5.6697×10⁻⁸  W/(m²·K⁴)   —— 斯特藩-玻尔兹曼常数

4. 对流散热功率 WF

  膜温  Tfilm = (Tc + Ta) / 2
  空气热导率   λf = 2.42×10⁻² + 7×10⁻⁵ · Tfilm          W/(m·K)         (3-74)
  空气运动粘度 ν    = 1.32×10⁻⁵ + 9.5×10⁻⁸ · Tfilm          m²/s            (3-76)
  雷诺数       Re = V·D / ν
  WF = 0.57 · π · λf · (Tc−Ta) · Re0.485              (3-73)

注：公式 (3-73) 为电力工程设计手册给出的综合简化公式，工程常用；等效于分项 Nusselt 准则（Nu = 0.65·Re0.2 + 0.23·Re0.61）经过"等效换热因子"归一后的近似，在 Re=100~3000 范围内误差 ≤ 2%。

5. 日照吸热功率 WS — 公式 (3-77)

  WS = αs · Js · D
      αs —— 导线表面吸热系数，光亮新线 0.35~0.46，旧线/涂黑防腐剂 0.9~0.95
      Js —— 日照强度，晴天 1000 W/m²

6. 输送容量

  S = √3 · U · I · n   (MVA)          P = S · cos(φ)   (MW)

💰经济电流密度计算说明 (DL/T 5582-2020)

经济电流与经济输送容量

  Peco = √3 · U · Ieco · n · cos(φ)
      Ieco = S · J
      式中：
      S — 导线计算截面 (铝截面, mm²)
      J — 经济电流密度 (A/mm²)，由 Tmax 和导线材料查表确定
      U — 系统标称电压 (kV)
      n — 分裂数
      cos(φ) — 功率因数

经济输送容量表示：在给定 Tmax 和电压等级下，当前导线截面对应的经济合理最大输送功率。

  • 选择导线截面和 Tmax → 自动读出经济电流密度 J
  • Ieco = S × J → 该截面可经济输送的电流
  • Peco = √3·U·Ieco·n·cosφ → 经济输送容量

注：年最大负荷利用小时数 Tmax 通过负荷预测或电力公司典型数据获取。经济电流密度用于以"年费用最小"原则选择导线截面，与热稳定极限载流量各自独立计算。

⚡电压降落与线损计算公式

线路电抗 X

  r = D / 2000                       （导线半径，m；D 为外径 mm）
  X = 0.1445 · lg(Deq / r) + 0.0157 / n          （Ω/km）
      式中：
      Deq — 各相导线间几何均距 (m)，取决于杆塔排列型式
      n — 每相分裂子导线数
      lg — 以 10 为底的对数

注：分裂导线对电抗的修正采用简化的 0.0157/n 近似，内部电抗与外部电抗合并，在工程常用范围内误差可接受。

电压降落 ΔU

  ΔU = √3 · Ieco · (R20 · cosφ + X · sinφ) · L / 1000      （kV）
  ΔU% = ΔU / U × 100                   （%）
      式中：
      Ieco — 经济电流 (A)
      R20 — 20℃直流电阻 (Ω/km)
      X — 单位长度电抗 (Ω/km)
      L — 线路长度 (km)
      cosφ / sinφ — 负荷功率因数及其无功分量

线损 ΔP

  ΔP = 3 · Ieco² · R20 · L / 1000              （kW）
  线损率 = ΔP / (√3 · U · Ieco · cosφ) × 100    （%）
