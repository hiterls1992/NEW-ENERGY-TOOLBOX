变换公式（平移距离 + 旋转角度三角函数）

AB → XY：
X = X₀ + k·(A·cosθ − B·sinθ)
Y = Y₀ + k·(A·sinθ + B·cosθ)

XY → AB：
A = [(X−X₀)·cosθ + (Y−Y₀)·sinθ] / k
B = [−(X−X₀)·sinθ + (Y−Y₀)·cosθ] / k

说明：
1. 本工具采用平面相似变换（四参数）：平移量（X₀、Y₀）+ 旋转角 θ + 比例因子 k，由两组不重合的对照点唯一确定。
2. 旋转角 θ 为「将 AB 坐标轴旋转到与 XY 坐标轴重合」的角度，逆时针为正、顺时针为负。
3. 当 k≈1 时，两坐标系单位与尺度一致，退化为纯刚体变换（仅平移 + 旋转）。示例中 k≈0.999，说明两套坐标均为米制、仅存在毫米级舍入误差。
4. 输入坐标建议保持相同小数位，X、Y 按米（3 位小数，毫米级）输出，A、B 按 3 位小数输出。
5. 结果可自行验算：将点 1、点 2 代入公式应精确还原原坐标。
